Project Description:
Cybertronian Factions Simulator is a game where you get to play as a cybertronian, either pick the Autobots, maintain justice and order across Cybertron, be a defender of freedom and peace, or join the Decepticons and conquer Cybertron, be one of the cybertronians who believe in "peace through tyranny" and rule with fear and power.

For this simulator we will be using classes such as a parent class Cybertronian, with attributes such as name, height, speed, attack, defense, health, alt mode(s), weapon(s), status, victories, defeats, and weapons. With possible methods:, now we would make the faction classes e.g. Autobots, Decepticons, etc. inherit from it and add extra attributes for each of the child classes. It's also possible we showcase polymorphism among the classes using method overriding and possibly use duck-typing.
